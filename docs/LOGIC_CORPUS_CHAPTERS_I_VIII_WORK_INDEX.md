## Per-item diagram procedure
1. Preserve exact source wording and location.
2. Record the passage-specific meaning; do not import external semantic/formal categories.
3. Diagram the sentence/structure and its parts.
4. Link to the exact source passage.
5. Diagram each part according to the meaning stated in that passage.
6. Cross-link only with evidence.
7. Tag SOURCE / USER PREMISE / DERIVED / PROPOSED PRECISION / UNRESOLVED.
