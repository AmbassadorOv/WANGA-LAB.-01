## Map layers
1. Source text and edition: exact chapter boundaries, section spans, variants.
2. Entities: every term, distinction, definition, example, and operation occurring in this chapter.
3. Occurrences: each appearance retains its local context and role.
4. Relations: source-observed relations, derived relations, hypotheses, unresolved relations.
5. Compositions: structures assembled from the chapter's own components.
6. Cross-chapter links: incoming/outgoing links to other chapter maps, with evidence.
7. Dynamic history: versioned changes, Spiral convergence, Vortex branching.
8. Artifacts: source passage, term cards, diagrams, tests, linked files.

## Required map record
`chapter_id, edition_id, start_locator, end_locator, entities[], occurrences[], relations[], compositions[], outgoing_links[], incoming_links[], evidence[], version`.

## Extraction rule
No chapter title, definition, relation, or semantic role is invented. Each is added only with a source locator. A chapter map can contain many views, but remains one chapter-scoped map.
