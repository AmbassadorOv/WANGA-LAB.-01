## Ground rules

- A map is a mutable, versioned model, not a static illustration.
- Source facts, derived relations, hypotheses, and unresolved items remain distinct.
- Every source-backed node or relation should carry a repository URL and, where possible, a file path and line/span locator.
- A repository's name or description does not prove its internal architecture.
- Existing structures are not silently merged; mappings preserve identity, context, and provenance.
- Spiral and Vortex are modeled as complementary transformation patterns over the same graph, not as fixed system tiers.
- Visualizations are projections of the graph. They are not the authoritative data store.
